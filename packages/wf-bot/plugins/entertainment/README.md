# 群聊娱乐插件

围绕每日签到、Warframe 奇遇、积分经济和群友对战构建的 Koishi 插件。

## 常用命令

- `签到`、`今日奇遇`、`我的资料`
- `挑战 @群友 [积分]`、`匹配对战`、`接受挑战`、`拒绝挑战`
- `战术复盘 [对战编号]`
- `积分商店`、`购买 商品名 [数量]`、`背包`
- `赠送 @群友 积分`
- `积分排行`、`对战排行`

## 积分商店

- 训练数据：25 积分，立即获得 20 经验。
- 对战券：20 积分，补充 1 张，上限 3 张。
- 战术增幅器：40 积分，下一场对战自动消耗并提供 6 战斗力。
- 护盾保险：35 积分，失败时自动消耗，使返还比例至少达到 30%。

“幸运坐标”奇遇会让当天首次购买享受八折。积分赠送要求双方当天已经签到，每位用户每天最多送出 50 积分。

## 公平规则

- 对战胜率限制在 15%～85%，战斗力高不代表必胜。
- 手动挑战受 MMR 差和基础战力差限制。
- 每天最多完成 5 场对战，每场双方各消耗 1 张对战券。
- 同一对手每天只能完成一场有效奖励对战。
- 每日奇遇只在首次符合条件的行为中生效。
