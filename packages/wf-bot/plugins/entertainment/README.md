# 群聊娱乐插件

围绕每日签到、Warframe 奇遇、积分经济和群友对战构建的 Koishi 插件。

签到卡中的今日运势使用六维雷达图展示：紫卡、交易、掉落、核桃、赏金、生息。六项数值按用户和日期固定生成，并保留文字运势与建议。

## 常用命令

- `签到`、`今日奇遇`、`我的资料`
- `对战`（随机匹配）、`对战 @群友 [积分]`（指定对战）、`接受挑战`、`拒绝挑战`
- `战术复盘 [对战编号]`
- `积分商店`、`购买 商品名 [数量]`、`背包`
- `赠送 @群友 积分`
- `积分排行`、`对战排行`
- `射爆`（群聊俄罗斯轮盘；中弹者禁言 1 分钟）
- 群聊消息包含“原神”时，自动禁言发言者 30 秒

`射爆` 使用每群独立、持久化的六发左轮状态，按顺序扣动扳机，中弹后立即重新装填；群内请求会依次结算。

## 积分商店

- 训练数据：25 积分，立即获得 20 经验。
- 对战券：20 积分，补充 1 张，上限 3 张。
- 战术增幅器：40 积分，下一场对战自动消耗并提供 6 战斗力。
- 护盾保险：35 积分，失败时自动消耗，使返还比例至少达到 30%。

“幸运坐标”奇遇会让当天首次购买享受八折。积分赠送要求双方当天已经签到，每位用户每天最多送出 50 积分。

## 公平规则

- 对战胜率限制在 15%～85%，战斗力高不代表必胜。
- `对战` 会随机选择 MMR 差距在允许范围内的群友并直接结算；指定对战双方 MMR 匹配时直接结算，不匹配时生成邀请，需对方发送「接受挑战」。
- 只有发起对战的一方消耗 1 张对战券，目标方不消耗对战券。
- 发起方支付完整对战积分；被挑战方支付一半。被挑战方获胜时，积分奖励、胜利奇遇积分和胜利经验均减半。
- 每天最多完成 5 场对战。
- 同一对手每天只能完成一场有效奖励对战。
- 每日奇遇只在首次符合条件的行为中生效。
