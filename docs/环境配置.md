# 环境配置

博客在服务器上要单独准备这些东西。前端和后端是本仓库的子模块，进程由本仓库的 PM2 配置启动。

## 软件

| 软件 | 要求 |
| --- | --- |
| Node.js | 20 |
| PostgreSQL | 14 或更高 |
| Nginx | 反向代理和上传文件 |
| PM2 | 进程管理 |
| certbot | 签发和续期 HTTPS 证书 |

## 目录

生产目录是 `/root/shichiya-blog`。拉取时要带上子模块：

```bash
git clone --recurse-submodules https://github.com/ShiChiYa7493/shichiya-blog.git
```

`uploads/` 必须对运行 `blog-api` 的用户可写。Nginx 的 `/uploads/` 要 alias 到这个目录，和仓库里的 `nginx.conf.example` 保持同一路径。

## 环境变量

后端 `packages/server/.env`，从 `.env.example` 复制：

| 变量 | 作用 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 连接串。库、用户要事先建好 |
| `JWT_SECRET` | 后台登录令牌签名。用 `openssl rand -base64 48` 生成 |
| `SITE_URL` | 站点公开地址，RSS 会用到 |
| `HOST` | 生产环境保持 `127.0.0.1` |
| `PORT` | `3001` |
| `NODE_ENV` | 生产环境为 `production` |

前端 `packages/frontend/.env`：

| 变量 | 作用 |
| --- | --- |
| `API_URL` | Next.js 服务端请求后端的地址，生产环境为 `http://127.0.0.1:3001` |

这两个文件不入库。

## 数据库

```bash
npm run db:migrate
npx -w packages/server prisma db seed
```

Seed 会创建管理员 `admin` / `admin123`。第一次登录后立刻改掉密码。

## 进程和端口

`ecosystem.config.js` 只管理这两个进程：

| 进程 | 端口 | 监听 |
| --- | --- | --- |
| `blog-web` | 3000 | `127.0.0.1` |
| `blog-api` | 3001 | `127.0.0.1` |

Nginx 监听 80 和 443，把 `/` 转到 3000，把 `/api/` 转到 3001，把 `/uploads/` 指到上传目录。`client_max_body_size` 至少 50MB，否则相册上传会返回 413。证书：

```bash
sudo certbot --nginx -d shichiya.cn -d www.shichiya.cn -d blog.shichiya.cn
```

3000 和 3001 不要对公网开放。

## 发布

在服务器上的仓库目录执行 `npm run deploy`。它会拉取代码和子模块、安装依赖、执行迁移、构建，然后只 reload `blog-web` 和 `blog-api`。
