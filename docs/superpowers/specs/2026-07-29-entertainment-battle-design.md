# QQ 群娱乐与对战系统设计

- 日期：2026-07-29
- 实现：`packages/wf-bot/plugins/entertainment`
- 边界：与 Warframe 数据域完全隔离，只共用 Koishi 实例与数据库服务

## 1. 核心循环

```text
签到 → 积分 / 经验 / 奇遇 → 匹配或挑战 → 战绩 / MMR → 排行榜
```

所有状态按群隔离。积分只作为机器人内部虚拟资源，不支持充值、现金兑换或用户转账。

## 2. 签到

- 基础积分：10。
- 每日随机积分：0～10，使用用户 ID 与日期固定种子，同日不可重摇。
- 连签奖励：第 N 天额外 +N，上限 +30；断签后从 1 开始。
- 每日获得 10 点经验和 1 张对战券，对战券最多保存 3 张。
- 每天固定抽取 1 个签到奇遇。签到型奇遇立即结算，对战型奇遇在首次对战时结算。

## 3. 战斗力与胜率

```text
基础战斗力 = 100
  + 等级 × 6
  + min(连签天数, 30) × 2
  + 每日随机积分 × 2
  + min(当前连胜, 5) × 3
```

奇遇对一场战斗的净影响限制在 `-20～+20`。历史总积分不计入战斗力，避免老用户永久压制新人。

```text
挑战者胜率 = clamp(
  50% + (挑战者战斗力 - 对手战斗力) ÷ 200 × 35%,
  15%,
  85%
)
```

胜负随机种子在接受挑战时固定，重渲染战报不会改变结果。MMR 使用 K=24 的 Elo 更新。

## 4. 公平与限流

- 手动挑战默认要求 MMR 差不超过 200、基础战力差不超过 30%。
- 同一对用户每天只能完成 1 场有效对战。
- 每人每天最多 5 场，且每场消耗 1 张对战券。
- 每位用户同一时间只能发出 1 条等待处理的邀请。
- 邀请默认 90 秒过期。
- 单场积分消耗为 5～20，默认 10。
- 双方积分进入奖池，胜者获得 80%；奇遇退款只能使用剩余奖池，不能凭空增发。

## 5. 奇遇

当前池包含 40 个以上奇遇，效果全部落在统一效果类型上：

- 固定战力、遇强加成、势均力敌加成、MMR 逆风加成。
- 削弱对方、战术扫描、先手。
- 即时积分、经验、额外对战券。
- 胜利赏金、失败退款、协同经验。

奇遇由纯数据定义；增加名称和文案不需要修改对战结算代码。抽取采用权重和固定日种子，不能通过重复调用命令重摇。

## 6. 命令

| 命令 | 作用 |
|---|---|
| `签到` | 领取每日奖励与奇遇 |
| `我的资料` / `积分` / `战斗力` | 查看个人状态 |
| `今日奇遇` | 查看奇遇及使用状态 |
| `挑战 @用户 10` | 发起指定积分消耗的挑战 |
| `匹配对战` | 按 MMR 寻找接近的对手 |
| `接受挑战` / `拒绝挑战` | 处理邀请 |
| `积分排行` | 查看群内积分榜 |
| `对战排行` | 查看群内 MMR 榜 |
